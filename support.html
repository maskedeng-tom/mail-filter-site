Mail Filterのセットアップ方法とよくあるトラブルについて説明します。

1. 一般的なIMAP設定

お使いのメールサービスがアプリ内に登録されていない場合は、手動でIMAP接続情報を入力してください。

  • ホスト名：メールサービスのIMAPサーバーのアドレス（例：imap.example.com）
  • ポート番号：通常は 993（SSL/TLS使用時）
  • SSL/TLS：特別な理由がない限り有効にしてください

2要素認証（2FA）を有効にしているメールサービスでは、通常のログインパスワードではなく「アプリパスワード」の発行が必要になる場合があります。各サービスのヘルプページを参照してください（下記プロバイダー別ガイド参照）。

2. Gmail（OAuth2連携）

Gmailアカウントは、アプリ内の「Googleでログイン」ボタンから連携します。

  1. アカウント追加画面でGmailアドレスを入力する
  2. ブラウザが開き、Googleの認証画面が表示される
  3. ログイン後、アクセス権限の確認画面が表示される
  4. スコープ確認のチェックボックスを必ずチェックしてから「許可」を選択する
  5. アプリに戻り、連携完了を確認する

手順4のチェックボックスにチェックが入っていないと、権限が正しく付与されず「認証に失敗しました」というエラーになります。接続エラーが出た場合は、アカウント設定画面から再認可を行い、チェックボックスの状態を確認してください。

4. よくあるトラブル

  • 認証エラーになる：2要素認証が有効な場合、通常のパスワードではなくアプリパスワードが必要です。上記プロバイダー別ガイドを確認してください。
  • 接続タイムアウトになる：ホスト名・ポート番号が正しいか、ネットワークのファイアウォールがIMAP通信（通常ポート993）をブロックしていないか確認してください。
  • Gmailで「認証に失敗しました」と表示される：上記「2. Gmail（OAuth2連携）」の手順4を参照し、スコープ確認のチェックボックスにチェックが入った状態で再認可してください。

5. それでも解決しない場合

GitHub Issuesにて、症状と使用しているメールサービスを添えてご報告ください。
